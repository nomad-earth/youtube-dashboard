Privacy Policy

Last updated: 2026-09-18

yt-dashboard ("this application") is a personal tool that helps its owner back up and analyze their own YouTube channel data.

What data this application accesses

  • YouTube Analytics data of the owner's own channel (views, watch time, subscribers, traffic sources) via YouTube Analytics API, read-only.
  • The owner's own Google Sheets, to store daily snapshots of the above data.

How data is used

All accessed data is stored only in the owner's own Google Sheets and GitHub Actions logs. This application does NOT collect, share, sell, or transmit any data to third parties. No analytics cookies, no tracking.

Data retention

Snapshot data is kept in the owner's Google Sheets for the owner's own historical analysis. The owner may delete it at any time by clearing the sheet.
